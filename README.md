# DSLab

A simple utility that converts .ds (DiffSingerScript) to .lab (Label) files
### Requirements

Java runtime (JDK-21) is required, OpenJDK-21 is recommended

### Usage

Activate:
```bash
java -jar DSLab.jar
```
Convert:
```bash
convert /path/to/ds/files
```
The path can be to a single file or to multiple files, the right conversion type is automatically used
